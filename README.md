# NPrD Generator Hub

Upload index.html dan .nojekyll ke root repository GitHub. Settings > Pages > Deploy from a branch > main > / (root) > Save. Ekstrak ZIP dahulu; jangan upload ZIP sebagai website.

Versi terbaru menambahkan Rancob Generator pada Divisi > Dokumen. Rancob memiliki Pendahuluan, alternatif formula dari RM Cost, spesifikasi dengan baris/kolom tambahan, dan lampiran. Formula adalah salinan kode bahan, usage (kg), dan percentage sebelum yield; harga tidak ikut dan sumber RM Cost tidak berubah. Skala lab/pabrik bisa dipilih ketika mengambil formula. Rincian P Minor tersedia dan dapat disertakan dalam PDF.

Rancob tersimpan lokal serta ikut Cadangkan Semua / Pulihkan. Tersedia pratinjau PDF, unduh PDF, salin dan hapus rancob. Semua fitur First Approval, CRQS dan generator lain tetap tersedia.

Data tetap di browser masing-masing, tidak sinkron antaruser. Untuk memakai data HTML offline di link baru, cadangkan lalu pulihkan pada generator yang sesuai. Pulihkan cadangan lama dahulu sebelum impor bahan dan harga terbaru, terutama harga per plant.

Perbaikan keamanan dari pemeriksaan sebelumnya belum diterapkan. Jangan upload cadangan JSON atau formula confidential ke repository.

P Minor dan COI pada Dokumen divisi dikelompokkan sebagai folder per proyek. Klik nama proyek atau Buka folder untuk melihat dokumen. Pencarian mencakup proyek dan dokumen. Data, cadangan, preview dan unduhan tidak dipindahkan.

Menu kiri dan isi kanan di dalam proyek menggunakan scroll terpisah. Posisi menu dipertahankan lintas tab, dan posisi isi kanan diingat per bagian selama aplikasi dibuka.

Scroll roda mouse/touchpad di atas input angka tidak mengubah usage, harga, atau nilai numerik lainnya. Scroll tetap bergerak pada area tabel/panel yang sesuai.

RM Cost Simulation: Edit P Minor di baris P Minor dapat mengganti kode dan deskripsi pada versi draft yang dipilih. Versi lama/final dan bahan/usage tidak berubah. Kode duplikat dalam satu versi ditolak.

Kartu versi dalam folder RM Cost Simulation menampilkan RM Cost per kg sebagai pengganti catatan. Nilai mengikuti perhitungan versi, termasuk yield dan sumber harga; data yang belum lengkap ditandai. Catatan asli tetap tersimpan.

Ambil RM Cost pada proyek: sumber dikelompokkan per produk/proyek, dengan versi dan RM Cost per kg di dalam kelompok yang bisa dibuka/ditutup. Pencarian tersedia; review dan penerapan formula tetap sama.
